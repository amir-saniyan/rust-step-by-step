# آموزش گام‌به‌گام زبان Rust

این مخزن شامل کتابی فارسی برای یادگیری زبان Rust است. کتاب در ۶۹ درس کوتاه، از مبانی تا مفاهیم پیشرفته، با مثال‌های کوچک و قابل‌اجرا پیش می‌رود.

موضوعات کتاب شامل متغیرها و توابع، مالکیت و قرض‌گیری، ساختار داده‌ها، مدیریت خطا، Generic و Trait، همزمانی و Async و مباحث پیشرفته‌ی زبان است.

## مطالعه‌ی کتاب

برای شروع، پیوند [https://amir-saniyan.github.io/rust-step-by-step](https://amir-saniyan.github.io/rust-step-by-step) را به‌ترتیب درس‌ها بخوانید و مثال‌ها را اجرا کنید. مثال‌ها برای Rust 1.85 یا جدیدتر و Edition 2024 نوشته شده‌اند.
